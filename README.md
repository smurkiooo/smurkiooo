## 🍵 Currently building

### [OolongAI-ops](https://github.com/smurkiooo/OolongAI-ops)

I’m building an AIOps agent that investigates simulated service incidents using metrics, logs, and traces. It cites the evidence behind each diagnosis and flags cases where the evidence is insufficient.

> **Research question**  
> Can QLoRA fine-tuning help Qwen3-1.7B diagnose incidents more accurately and with fewer checks than prompting alone?
